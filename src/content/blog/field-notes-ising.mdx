## The model

Put a spin $s_i \in \{-1, +1\}$ on every site of a lattice. The energy is

$$
H = -J \sum_{\langle i,j \rangle} s_i s_j - h \sum_i s_i
$$

where the first sum runs over neighbouring pairs<Sidenote num="1">Nearest neighbours only. Longer-range couplings change the universality class.</Sidenote>. At temperature $T$ each configuration appears with probability proportional to $e^{-H/k_B T}$.

### The critical point

In two dimensions, Onsager found the exact critical temperature <Cite id="onsager1944" />:

$$
T_c = \frac{2J}{k_B \ln(1 + \sqrt{2})} \approx 2.269\,J/k_B
$$

Below it, the system picks a side. Above it, it doesn't.

## Metropolis in a dozen lines

The update rule in the explorable comes from <Cite id="metropolis1953" />:

```python
import numpy as np

def sweep(spins, beta, rng):
    n = spins.shape[0]
    for _ in range(spins.size):
        i, j = rng.integers(n, size=2)
        nb = spins[(i+1) % n, j] + spins[(i-1) % n, j] + spins[i, (j+1) % n] + spins[i, (j-1) % n]
        dE = 2 * spins[i, j] * nb
        if dE <= 0 or rng.random() < np.exp(-beta * dE):
            spins[i, j] *= -1
```

| Quantity | Symbol | Behaviour at $T_c$ |
|---|---|---|
| Correlation length | $\xi$ | diverges |
| Susceptibility | $\chi$ | diverges |
| Magnetisation | $m$ | $\to 0$ continuously |

> Everything interesting happens where nothing is stable.
